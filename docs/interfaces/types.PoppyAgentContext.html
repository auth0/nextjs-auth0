    Interface PoppyAgentContext

    A request driven by a Personal Agent. It mirrors the ID token Auth0 issued for the join: the token's own sub and sub_profile, and its whole act claim, which names the agent. state and scopes are the SDK's.

        state: "guest" | "signed_in";
        sub: string;
        sub_profile?: string;
    }

    act

    act: PoppyActClaim

    The ID token's act claim, as Auth0 sent it: the agent acting. Its sub is the Auth0 agent ID, or the agent's client metadata URL when no Auth0 agent is linked.

    scopes

    scopes: string[]

    The scopes granted to the website's access token. Always empty for a guest.

    Auth0 grants the website no more than the customer approved for the agent, plus OpenID scopes such as openid and profile, so these can be fewer than the agent's scopes but never more.

    • Defined in src/types/poppy.ts:185

    state

    state: "guest" | "signed_in"

    "guest" before the customer approves the agent; "signed_in" once the agent acts in the customer's account. A guest join ends any session the browser had, so getSession() is null for a guest.

    • Defined in src/types/poppy.ts:160

    sub

    sub: string

    The ID token's own sub, not the agent's: the customer's Auth0 user ID once signed in (the same as session.user.sub), or the anonymous anon_poppy@… subject for a guest. The agent is act.sub.
