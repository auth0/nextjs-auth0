    OptionalonVerificationRequired

    onVerificationRequired?: (
        context: PasskeyVerificationContext,
    ) => Promise<Partial<Record<PasskeyVerificationIdentifier, string>>>

    Browser passkey.signup() only; ignored by the server register().

    Called when the connection requires identifier verification. Resolve with the codes the user entered. It is called before the passkey is created, and again with the remaining identifiers if a code is rejected. The same passkey is resubmitted, so the user is not prompted for it twice.

    Without this callback a signup that requires verification fails with PasskeyGetTokenError code verification_required.
